Their compatibility paths under `evaluator/` are retained so original test identities and source pins remain inspectable. `SOURCE_PINS.json` identifies the original surviving G2-FINAL bytes.

These answers are public in this candidate. New trials using them are **not blind or held-out evaluations**. Historical receipts are evidence only for their original pinned runs; publication does not create a new independent result. Original failures, SKIPs, B/C NOT_IMPLEMENTED, incomplete G24 work and the FalkorDB SIGSEGV/139 limitation remain limitations. No model or causal improvement is established by the offline reproduction.
