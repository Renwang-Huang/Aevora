# 产品方向与差距

Aevora 面向编码 Agent 的工程经验积累、相关召回与验证。目标是让真实任务减少
重复错误和返工，并能说明经验的来源、适用条件与失效边界。条目、Query 和自测
数量不作为能力增长证明。普通观察自动保存，常设策略内的可信作业自动晋升，
人工处理例外、策略调整与抽样质量检查。

## 长期目标与交付顺序

长期目标是让编码Agent在连续项目开发中积累可追溯知识，减少重复错误和返工，
同时及时识别不适用、过期和相反证据。默认交付保持Go单二进制、嵌入SQLite，
复用官方Agent运行时和成熟协议；可选模型服务负责提出或排序内容，不取得发布权限。

| 依赖顺序 | 目标 | 验收依据 |
|---|---|---|
| 连续工程输入 | 一个实际项目、一个主入口持续采集；正常编辑后可安全交接上下文 | 自然任务、支持范围内来源覆盖、显式跳过原因；旧查询不改写，未知写不重放 |
| 可复用知识 | 事件、任务小结、结构化假设、核验方法分层；跨任务融合与反证 | 前提、动作、检查、限制逐项关联来源；固定项目检查计划；错误修复被拒绝 |
| 有效检索 | 混合检索、观察读取和合理放弃，正确处理版本与中英表达 | 开发集与冻结测试集隔离；召回、无答案误召回、延迟和成本一起报告 |
| 方法与技能演化 | 已验证方法形成技能，持续复验、更新和淘汰 | 新任务快照复现、前提不符拒绝、反证失效、可恢复历史 |
| 可衡量任务收益 | 经验确实被使用并帮助完成独立验收任务 | 同模型、设置、预算和初始快照的对照；重复错误、成功率、返工、时间与token |

首个日用试点建议至少20个自然任务覆盖3类工作，约定范围事件覆盖率目标不低于95%，
所有跳过有原因，零静默丢失。这些是未来试点门槛，不是当前成绩或统计收益证明。
后续检索独立测试建议至少200条，初拟Recall@5≥0.90、无答案误召回率≤0.10，
在基线与预算确定前确认定义。旧公开标签只用于回归，不能当作独立盲测。

每轮开发必须实际使用已安装的Aevora：选择方案前查询，核对线索与源码，记录实际调查、
采用或拒绝及原因；开发检查接入工程来源，检查后核对摄入与整理。发现断点优先定位修复。
实际协议调用、自用声明、检查成功和独立结果分别报告；未观测到收益就保留未知或负结果。
普通观察自动保存并可作低信任线索；常设策略内自动核验与晋升；人工负责策略、冲突和抽查。

当前先补工程输入：显式本地检查入口可复用已有outbox与整理作业，适合开发中的持续自用。
官方客户端自然采集、无需重开会话的上下文交接及长期预算轮转仍需后续整体验收，
不能用新增入口的自测替代。每个功能独立分支验证，集成验收通过后合入本地main。

## 当前工作顺序

| 方向 | 已具备的基础 | 继续弥补的差距 |
|---|---|---|
| 任务相关召回 | 60条固定及50条更难公开合成查询；SQLite FTS5/BM25、可选回环嵌入/RRF与固定TEI重排、精简卡片、明确降级 | 困难集无答案误召回、独立测试与真实模型质量/成本/任务收益 |
| 目标上下文 | 受保护项目名、Git/工作区元数据、根与一级模块清单摘要、查询时变化检查；同 Host 白名单内工作目录路由，未登记目录保持目标未知 | 路由取决于客户端传承的目录；全内容证明、实际安装依赖、官方运行时模型配置与持续事件 |
| 自动采集 | 有界诊断信号、持久outbox与确认、app-server工程来源、显式本地检查采集、保守检查分类、回调样本与可逆隔离 | 官方hook实际执行与自然覆盖、更多有界工程语义、更广泛回声防护及故障验证 |
| 自动整理 | 独立回执与常设策略晋升；诊断分组、跨回合工程来源、持久增量账本与有界摘要；JSON 工件独立核验可接常设策略 | 更深入工程语义提炼、冲突判断、更多独立核验器与真实效用评估 |
| 失效与反证 | 发布/撤回门禁、来源撤销依赖传播、工件/策略变化撤回、不可变查询快照 | 更广泛的版本失效、反证解释、降权与重建 |
| 技能学习 | 候选和条件经验 | 带前提、动作、检查、来源和恢复的技能形成与淘汰 |
| 实际收益 | 查询/声明/核验/收益分开记录 | 原生记忆、文件搜索和成熟方案的同条件对照 |
| 使用体验 | 本地 Console、项目与任务工作流；可记录候选使用反馈、整理状态与阻塞原因；MCP/Console 读取工程来源 | 捕获、检索、实际使用、失败及下一步的持续衔接和清楚呈现 |
| 企业交付 | 可审计的本地内核 | 真实需求下的共享权限、隔离、运维与 SLA；不提前宣称 |

每项功能独立分支开发，校验合格再合入本地 main。一次性研究、差距登记、
运行产物和验收记录在独立仓库外目录保存；不改写旧失败或历史证据。

## 实现参考与选择

已有实现优先于自建整套框架：

- [ReMe](https://github.com/agentscope-ai/ReMe)：采集、daily/digest 与防召回回声。
- [Hindsight](https://github.com/vectorize-io/hindsight)：分层整理、来源与预算化检索。
- [claude-mem](https://github.com/thedotmack/claude-mem)：可靠交付与渐进详情。
- [Graphiti](https://github.com/getzep/graphiti)：变化事实的时间与失效。
- [Letta Code](https://github.com/letta-ai/letta-code)、[Hermes](https://github.com/NousResearch/hermes-agent)：记忆/技能维护。
- [GEPA](https://github.com/gepa-ai/gepa)：由独立指标选择候选策略。

当前词法检索复用现有 [SQLite FTS5](https://www.sqlite.org/fts5.html)。默认本地交付
继续不要求外部数据库服务、Python 或 Node。可选语义检索按回环适配层提供；
优化器后续按可替换适配层评估，只产生候选，不取得独立验收或发布权限。

任务描述只影响相关性，可信事实才影响适用性。来源、版本历史、LLM 反思或反馈
计数各自有用途，不自动证明工程成功、真实采纳或因果收益。商业平台、公开库和
可下载二进制按各自实际版本与许可比较，不把供应商成绩归给其他实现。

工程来源接入、整理账本、独立 JSON 契约核验和持续巡视见 [工程任务记忆](TASK_MEMORY.md)。
