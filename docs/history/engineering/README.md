# Historical engineering program source

These are source texts of the surviving one-off phase-local harnesses, not private raw evidence, model sessions or credentials. Duplicate source bytes map to one published copy in INDEX.csv. Original hashes and publication-copy hashes are separate; personal home-directory names are redacted in copies. Original sealed files were not changed.

They preserve debugging and experimental methodology, including G24 calibration, preregistration, fairness, native-boundary probes and packaging failures. Their fixed historical deployment/archive assumptions are not current runtime defaults. Do not execute them against existing deployments: use the maintained tools described in docs/DEBUGGING.md and explicitly owned external outputs. A few unfinished drafts (including report_release_pre_syntax_fix.py) intentionally retain historical syntax errors. Shipping them does not claim they passed, that G24 Pilot/Formal completed, or that any historical result was rerun.

The active application/Benchmark/Oracle and current test profiles are outside this archival namespace. Phase-local scripts requiring an unavailable historical archive retain that limitation; no fabricated fixture is substituted for authentic evidence.
