## Bounded document representation
The executable rc2 representation stores `document={document_sha256,document_utf8_bytes,chunks:[{id,index,sha256}]}` inside the common graph root. This is a documented wire/storage delta from the earlier proposed stand-alone document_manifest schema, which remains a design-only interchange schema. It is not silently claimed implemented. SnapshotChunk contains document_id/index/text/chunk_sha256 and common fields. Actual HAS_CHUNK edges, order, count, duplicate indexes, tenant and complete SHA are verified. Each chunk<=65536 UTF8 bytes, <=128 chunks, document<=8MiB, record<=262144. Publication listings and QuerySnapshot use the same loader. Required shape mismatches error, not partial recommendations.
