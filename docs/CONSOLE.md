# 查看活动与经验

通过 `aevora status --project my-project` 找到当前Console地址，在本机浏览器打开。
Console只读，显示实际记录，不负责执行模型任务或审批。

| 页面 | 可以了解什么 |
|---|---|
| 活动与建议 | 当前连接、任务、查询，以及已有查询得到的建议 |
| 经验库与证据 | 已存经验、适用条件、来源和支持/反例 |
| 核验与发布 | 候选状态、待补信息和生命周期 |

第一次使用时，先看页面用途与下一步提示。项目计数描述全项目，下方列表可能分页，
不能把当前页条数当成全部记录。空库、新任务和查询没有命中都是有效状态。

观察与查询记录不是任务成功证明。UNTRUSTED表示未核验声明；APPLY/VERIFY/ABSTAIN
分别描述当前条件下的适用性。查看实际条件与来源后再决定如何使用。

LIVE显示当前项目数据；REPLAY是内置的只读历史示例，可用`aevora demo`体验。
示例不发起模型请求，也不会为你的项目预置经验。LIVE连接失败时不会静默显示旧示例。

页面默认自动刷新；展开证据时可查看来源、版本和状态。当前界面不提供公网登录、
多租户共享或任意远程控制，默认保持loopback访问。
