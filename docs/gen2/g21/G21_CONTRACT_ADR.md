# rc2 decisions
Reuse GraphRepository transport, official SDK, existing strict equality/governance and PublicProjection lossless entries. Add one explicit v2 repository and arbitration extension, no alternative orchestrator. Host registration is the OS/local authority root, not a hash signature or Agent bool. Semantic manifests are complete closure catalogues, not trust by JSON shape. Current-scope finite refusal is acceptable; truncation is forbidden. Capability revoke/send can linearize locally; database epoch versus network byte delivery cannot be a distributed atomic transaction. Disclose residual race and require all controlled writers honor Host synchronization. G22 publication is a frozen handoff, not implemented acceptance.

Final implementation amendments: authenticated per-scope graph catalogues close demonstrated native-index omission; Broker output authorization uses its captured Host environment (not process-global current tenant); non-sensitive read_scope enables exact delivery hash auditing; default product record times are real UTC and cached recommendations are re-arbitrated at current time. The final catalogue/epoch state must be fenced together by G22. Synthetic catalogue writers are not accepted Host publishers.
