# 限制与排查

Aevora 当前面向可信本地开发者。Console 为 loopback 只读界面，scoped MCP
不等同于面向敌对程序的文件系统沙箱，也不宣称生产多租户能力。
领域事实目录由发行版本控制，目前增加原生运行时领域；其他工程领域仍需审查后
扩展。原生任务检索使用 FTS5/BM25、中文片段和受控工程别名，在有界候选上读取
证据，不再受旧条件诊断的256条语料枚举限制。默认词法可能漏检无词面重合的任务；
可选本地嵌入器与 RRF 提供语义通道，但质量取决于模型与阈值，合成测试不是实际效果证明。
服务故障明确降级；观察 ranked 仍为词法。冷启动或连接重建时需要重建临时索引，规模成本需按
实际语料测量；不以小型回归承诺生产容量。旧维护者条件诊断仍保留原读取预算。
跨客户端完整生命周期采集、自动整理和真实收益对照尚待后续迭代。
旧固定日常连接继续使用原任务；需要隔离任务时使用 task run。

`target_*`包括已注册项目、Git HEAD/分支、有界 Git 状态/变化文件元数据、根与一级模块的
固定清单/锁文件汇总及其版本声明。模块发现超过限额时范围退回根目录并明确披露；
不同模块声明不一致时单值版本保持未知。它不证明全部未提交内容、实际已安装依赖、模型覆盖
参数或测试结果。新指纹任务在查询前后检测变化并要求新任务，不自动改写固定事实。
缺少任务 query 不再把环境匹配视为任务建议；补充公开描述后重新查询。

| 状态 | 检查与处理 |
|---|---|
| 图为空 | health 后做实际 query；空候选不需要补造 seed |
| GraphUnavailable | 核对自己实例的健康、loopback 端口、graph 和秘密文件权限 |
| HOST_CONFIG_REQUIRED | 用 configure 保存 Host profile；新终端自动加载默认文件，其他项目用 --config PATH |
| HOST_CONFIG_EXISTS | 已有配置不会覆盖；先 health，明确编辑或用 --output 新建另一项目配置 |
| DB_CREDENTIAL_FILE_UNAVAILABLE | 检查 profile 的 password_file 引用和所属 0600 文件，不打印内容 |
| SESSION_ALREADY_RUNNING | 使用已有 Host，或正常停止后重复启动；并行任务选择独立会话根 |
| SESSION_PATH_EXISTS | 旧事件不覆盖；改用 profile/--session-root 自动创建，或选择全新显式路径 |
| SESSION_PATH_TOO_LONG | 配置更短的绝对会话根，保留旧目录与事件 |
| CONSOLE_PORT_IN_USE | Demo 默认 17804，LIVE 默认 17805；打开已确认的目标服务或显式 --port 另选端口 |
| MCP 不可用 | 核对 Host READY、grant 所有权、同一 Run 与 socket；配置存在不证明调用成功 |
| Grant 撤销/到期 | 建立新的所属通道和会话，不复用已撤销 token |
| API Forbidden | 核对 loopback Host/Origin；浏览器不需要 DB/admin 密码 |
| Replay 拒绝 | 核对独立 pin、原始包和普通文件；不为篡改内容生成新 pin |
| Provider/SSE/429 | 保留错误和重试记录，检查明确配置的服务，不静默降级模型 |
| 结果不完整 | 区分查询、候选、实际工程结果和观察，缺失信息保持 unavailable |

完整的首次与再次启动命令见[快速开始](QUICKSTART.md)。新版 connector 可保留下游
MCP 会话；自动接入只在事实与授权未改变时恢复同一 Run。固定绑定需要可信入口
重新授权；版本或条件变化、旧进程已退出时需要客户端重新连接。连接恢复不会重放
已中断且结果未知的业务调用。Console 可自动跟随当前 Host。
崩溃残留 grant 不会被新会话选择，旧证据仍保留；会话根不能整体提交或归档。

## 持久化与并发

原生SQLite使用WAL、synchronous FULL、外键、受控单写连接与不可变记录约束。
业务写入与operation结果在同一事务提交；客户端响应、审计送达和数据库提交分别表达。
最终LifecycleHead复查使用独立新鲜读，不能沿用旧快照。备份为VACUUM INTO一致性
文件，恢复到新项目；不使用活动WAL文件的裸复制。原生平台、强杀恢复、真实断电和
文件系统故障是不同验证范围，交叉构建不证明这些运行行为。

### Python/FalkorDB 对照

部署固定引擎并使用 RDB。数据库确认写入不等于已经持久化：恢复覆盖最后
完成的 SAVE，进程 SIGKILL 后未保存的尾部会丢失。`save 60 1` 不是严格的
最大丢失时长承诺，保存可能延迟或失败。隔离验证覆盖完成 SAVE 后强杀、
BGSAVE 进行中强杀保留旧 RDB、截断 RDB 拒绝启动，以及经 pin 核对的冷恢复；
这些进程实验不证明物理断电、设备缓存或文件系统损坏后的零丢失。

当前 v4.20.4 固定镜像的合成 AOF 样本覆盖约束、发布证据、查询快照、
撤回和重写后的强杀重载，未复现旧 AOF reload 故障。旧失败归档未重放，
不能据此宣称所有 AOF 故障已修复；产品部署仍显式关闭 AOF。

来源导入、反馈和阶段化发布可在部分语句已完成时中断；恢复后使用原始
可信输入重试。来源最后关联才可准入，`PUBLISHING` 不可检索，反馈最后才
写完成记录；保留部分数据以供核查，不做自动回滚。重试期间输入或暴露事实
改变可能触发不可变冲突，需要 Host 处理，不能改写旧记录来强行恢复。

候选状态转移在单条写语句中核对 head；生命周期读取在末尾复查 head，
观察到并发变化时明确失败，要求重新读取。发布重试观察到撤回时拒绝返回
成功。多语句操作仍不是全局事务；有界复查和 Console 分页仍不是原子或
可串行化快照。恢复操作见[部署说明](../deploy/README.md#持久化与恢复)。

## 证据与安全

同 UID / shared-kernel 开发环境、资源采样与 prompt injection 都有边界。
既有实验中的原生跨进程 UDS 限制、运行时 EOL 和内核 controller 前提需要
在相应环境重新核验，不能用本地回放或安全进程内检查证明已解决。

Agent 决策与项目自测保持不可信/外部观察。可信结果由独立 Host 来源验证
产生，任务 PASS 不证明经验采纳、统计优势或因果改善。本地摘要支持字节
一致性，不提供签名、第三方不可变存储或模型权重证明。

图/API 按资源分页并在数据库中筛选 Run，累计容量不再触发整图读取上限。
单请求预算和固定深度邻域仍可能省略节点，界面披露页与局部范围；未遍历的
可用经验和待处理候选总数保持 UNKNOWN。游标不是一致性快照，较早 ID 的新写入
需要回到首页查看；过大的单页或单个证明仍会返回 413，可缩小页或选择具体对象。
LIVE 失败不会
展示旧推荐或自动回退 Replay。发布不包含私有真值、原始秘密或个人身份。
