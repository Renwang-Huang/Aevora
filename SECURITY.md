# Security and privacy

Do not publish credentials, private Oracle or reference code, raw Agent logs,
Host authority pins, scoped capability files, user/account metadata or DB volumes.
The local public Demo contains only owned synthetic data and a selected sanitized
historical summary. It is not an authenticated hosted service.

Report a suspected issue privately to the repository owner through GitHub private
vulnerability reporting when enabled. If unavailable, contact the owner without
posting secrets or detailed private material in a public issue. No response SLA
or claim of absence of vulnerabilities is made. See docs/LIMITATIONS.md.
