# Security and privacy

The [full-project scope](FULL_PROJECT_SCOPE_AND_LICENSE.md) includes the actual
Oracle, formerly hidden tests/reference answers and Trusted Host implementation.
These public historical evaluation materials are no longer future blind tests.
Do not publish real credentials, signing private keys, production Host
registries/grants/scoped capabilities, original private model conversations,
sensitive user/account data or unsafe raw run/database contents. Some historical
run evidence remains unpublished. Source availability does not grant production
authority or make original private records independently verifiable.

The local public demo contains owned synthetic data and a selected sanitized
historical summary. It is not an authenticated hosted service, and its synthetic
registry is not production Host authorization.

Report a suspected issue privately to the repository owner through GitHub private
vulnerability reporting when enabled. If unavailable, contact the owner without
posting secrets or detailed private material in a public issue. No response SLA
or claim of absence of vulnerabilities is made. See docs/LIMITATIONS.md.
